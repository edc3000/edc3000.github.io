30 秒背诵版

去掉 softmax、换个乘法顺序：训练随长度线性增长，推理状态大小固定；代价是记忆容量有限、精确检索变弱

原理：softmax 注意力 softmax(QK⊤)V\mathrm{softmax}(QK^\top)Vsoftmax(QK⊤)V 必须先算 n×nn\times nn×n 的分数矩阵，计算 O(n2d)O(n^2d)O(n2d)。线性注意力把相似度 exp⁡(q⊤k)\exp(q^\top k)exp(q⊤k) 换成 ϕ(q)⊤ϕ(k)\phi(q)^\top\phi(k)ϕ(q)⊤ϕ(k)，利用结合律先算 ϕ(K)⊤V\phi(K)^\top Vϕ(K)⊤V，它只有 d×dd\times dd×d，计算降到 O(nd2)O(nd^2)O(nd2)。

RNN 视角：因果情况下维护一个状态 St=St−1+vtkt⊤S_t=S_{t-1}+v_tk_t^\topSt​=St−1​+vt​kt⊤​，输出 ot=Stqto_t=S_tq_tot​=St​qt​。状态大小固定，生成每个 token 都是 O(d2)O(d^2)O(d2)，没有随长度增长的 KV cache。训练用分块算法：块之间传状态，块内部用矩阵乘法并行。

短板：整段历史压进一个 d×dd\times dd×d 的矩阵，容量有限，只加不减还会相互干扰，大海捞针、精确复制这类检索任务不如 softmax 注意力。

改进：加遗忘门（RetNet、Mamba2、GLA），用 delta rule 先擦掉旧值再写入（DeltaNet），两者结合就是 Gated DeltaNet：St=αtSt−1(I−βtktkt⊤)+βtvtkt⊤S_t=\alpha_tS_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\topSt​=αt​St−1​(I−βt​kt​kt⊤​)+βt​vt​kt⊤​。实际模型都用混合架构：Qwen3-Next、Qwen3.5、Kimi Linear 是 3:1，MiniMax-01 是 7:1，少量全注意力层负责精确检索。

动机

为什么要线性注意力

训练：计算随长度平方增长 prefill

注意力要算 n×nn\times nn×n 的分数矩阵，单头计算量 O(n2d)O(n^2d)O(n2d)。FlashAttention 解决的是显存（不把 n×nn\times nn×n 矩阵写回显存），计算量一点没少。长度从 8K 拉到 128K，注意力的计算量涨 256 倍，而 FFN 只涨 16 倍，长序列下注意力成了大头。

推理：KV cache 随长度线性增长 decode

每生成一个 token 都要读一遍整个 KV cache，decode 是访存瓶颈。以 Llama-3-8B 为例（32 层，8 个 KV 头，head_dim 128，BF16），每个 token 的 cache 是 2×32×8×128×2=1282\times32\times8\times128\times2=1282×32×8×128×2=128 KiB，128K 上下文就要 16 GiB，比 BF16 权重本身还大，batch 也开不大。

线性注意力想同时解决两件事：训练计算随长度线性增长，推理只保留一个固定大小的状态。

原理

原理：去掉 softmax，换个乘法顺序

把注意力写成“相似度加权平均”的一般形式：

oi=∑jsim(qi,kj) vj∑jsim(qi,kj),softmax 注意力： sim(q,k)=exp⁡(q⊤kd)o_i=\frac{\sum_j\mathrm{sim}(q_i,k_j)\,v_j}{\sum_j\mathrm{sim}(q_i,k_j)},\qquad \text{softmax 注意力：}\ \mathrm{sim}(q,k)=\exp\Big(\frac{q^\top k}{\sqrt{d}}\Big)oi​=∑j​sim(qi​,kj​)∑j​sim(qi​,kj​)vj​​,softmax 注意力： sim(q,k)=exp(d​q⊤k​)

softmax 为什么不能这么做

exp⁡(q⊤k)\exp(q^\top k)exp(q⊤k) 拆不成有限维特征的内积，它对应的特征空间是无限维的，所以 qqq 和 kkk 分不开，只能老老实实先算 n×nn\times nn×n 的分数。Performer 用随机特征去近似 exp⁡\expexp，是无偏估计，但要很多特征才准，现在已经不是主流。

ϕ\phiϕ 怎么选，分母要不要 实现细节

原论文用 ϕ(x)=elu(x)+1\phi(x)=\mathrm{elu}(x)+1ϕ(x)=elu(x)+1，保证特征为正，分母不会是 0、权重非负。后来发现分母可能很接近 0，导致梯度不稳定（TransNormer 的分析），所以现在的模型大多去掉分母，在输出后接 RMSNorm 或 GroupNorm 稳住数值；ϕ\phiϕ 也常用 SiLU 加 L2 归一化，甚至直接不用。

要注意一点：现在说的“线性注意力”大多已经不是在近似 softmax，而是直接换成另一种机制。它和 softmax 注意力共享 QQQ、KKK、VVV 的形式，但计算的东西不一样。

训练

训练：分块并行

并行形式：又变回平方 易错

训练时整段序列一起算，因果要加掩码：

O=(ϕ(Q)ϕ(K)⊤⊙M)VO=\big(\phi(Q)\phi(K)^\top\odot M\big)VO=(ϕ(Q)ϕ(K)⊤⊙M)V

掩码 MMM 夹在中间，结合律用不了，必须先算出 n×nn\times nn×n 的矩阵，复杂度回到 O(n2d)O(n^2d)O(n2d)。

递推形式：太慢

按 t=1,…,nt=1,\dots,nt=1,…,n 一步步更新 StS_tSt​，计算是线性的，但有 nnn 步串行，每步只是小矩阵的外积和矩阵向量乘，用不上 Tensor Core；反向传播还要存每一步的 StS_tSt​，显存是 nd2nd^2nd2。

分块（chunkwise）把两者结合起来：序列切成长度为 CCC 的块，块之间按递推传状态，块内部用带掩码的并行形式。第 iii 块（省略 ϕ\phiϕ 和分母，Q[i]Q_{[i]}Q[i]​ 等是块内的行）：

O[i]=Q[i]S[i−1]⊤⏟块间：之前所有块+(Q[i]K[i]⊤⊙M)V[i]⏟块内：带掩码,S[i]=S[i−1]+V[i]⊤K[i]O_{[i]}=\underbrace{Q_{[i]}S_{[i-1]}^\top}_{\text{块间：之前所有块}}+\underbrace{\big(Q_{[i]}K_{[i]}^\top\odot M\big)V_{[i]}}_{\text{块内：带掩码}},\qquad S_{[i]}=S_{[i-1]}+V_{[i]}^\top K_{[i]}O[i]​=块间：之前所有块Q[i]​S[i−1]⊤​​​+块内：带掩码(Q[i]​K[i]⊤​⊙M)V[i]​​​,S[i]​=S[i−1]​+V[i]⊤​K[i]​

总复杂度 O(nCd+nd2)O(nCd+nd^2)O(nCd+nd2)，CCC 一般取 64 左右，全部是矩阵乘法，能用满 Tensor Core，串行步数从 nnn 降到 n/Cn/Cn/C。Lightning Attention（MiniMax-01）、flash-linear-attention 库的 kernel 都是这个思路。带 delta rule 的变体，块内还要把一串 (I−βtktkt⊤)(I-\beta_tk_tk_t^\top)(I−βt​kt​kt⊤​) 的连乘转成矩阵乘法（WY 表示、UT 变换），思路相同。

取舍

短板：为什么效果不如 softmax

记忆容量有限 根本原因

状态只有 dk×dvd_k\times d_vdk​×dv​ 个数。dkd_kdk​ 维空间里最多只有 dkd_kdk​ 个两两正交的 key，写入超过 dkd_kdk​ 对之后，上面那个串扰项一定不为 0。而且纯加法只加不减，写进去就擦不掉，历史越长越乱。

检索和复制弱

大海捞针、多查询联想检索（MQAR）、照抄一段长文本这类任务，需要原样找回前文。softmax 注意力把每个 token 都存着；固定大小的状态做不到：要原样复制长度为 LLL 的串，状态至少要能存下 LLL 个 token 的信息，所以状态大小固定的模型在复制任务上一定会输（Repeat After Me）。Zoology 发现线性注意力类模型和 Transformer 的差距主要就在这类检索上。

注意力不够尖锐

exp⁡\expexp 能把最大的分数放大，让注意力集中到少数几个 token 上；ϕ(q)⊤ϕ(k)\phi(q)^\top\phi(k)ϕ(q)⊤ϕ(k) 没有这种放大，权重容易摊得很平（attention dilution）。从矩阵上看，ϕ(Q)ϕ(K)⊤\phi(Q)\phi(K)^\topϕ(Q)ϕ(K)⊤ 的秩不超过 dkd_kdk​，表达不了任意的注意力模式。

没有“新近”偏好

纯加法下，第 1 个 token 和刚刚那个 token 权重一样，模型分不清远近，也没法主动忘掉无关的内容。这正是后来加衰减门的原因；位置信息则靠衰减和一个短卷积来提供。

βt=1\beta_t=1βt​=1 时直接把 ktk_tkt​ 对应的旧值换成 vtv_tvt​，不会越堆越乱。纯线性注意力相当于用损失 −⟨Skt,vt⟩-\langle Sk_t,v_t\rangle−⟨Skt​,vt​⟩ 做梯度下降，这个损失没有下界，只会一直往里加。

Gated DeltaNet：两者结合 Qwen3-Next / Qwen3.5

αt\alpha_tαt​ 负责快速整体遗忘，βt\beta_tβt​ 负责定向改写某一条记忆，两者互补：只有衰减时改不了某一条，只有 delta rule 时清不空。实现上 qqq、kkk、vvv 先过因果短卷积和 SiLU，qqq、kkk 做 L2 归一化，输出过 RMSNorm 后再乘一个 SiLU 门。在 Qwen3-Next 里它占 75% 的层，详见 Qwen3 → Qwen3.5 架构演进。

和 SSM、Mamba 的关系

Mamba2 论文（SSD）证明：标量衰减的选择性 SSM 和带衰减掩码的线性注意力是同一个东西的两种算法，SSM 里的 BtB_tBt​、CtC_tCt​、xtx_txt​ 分别对应 ktk_tkt​、qtq_tqt​、vtv_tvt​。现在线性注意力、SSM、线性 RNN 基本归为一类：固定大小的矩阵状态 + 门控递推，区别只在状态怎么更新。

落地

混合架构：为什么不全换成线性注意力

纯线性注意力在检索任务上差距明显，所以落地的模型都是混合：大部分层用线性注意力，隔几层放一层全注意力。KV cache 只有全注意力层有，3:1 时大约降到原来的 1/4，线性层的状态是一个和长度无关的常数。

反例：MiniMax-M2 又回到全注意力 要会说

MiniMax-01 用了 7:1 混合，但下一代 M2 换回了全注意力。官方博客的解释是：小规模评测里混合模型和全注意力差不多，规模上去后在复杂多跳推理等任务上暴露出差距，而且这种差距很难提前测出来；线性注意力的推理基础设施也不成熟，对数值精度更敏感。Kimi Linear 则报告在同样训练配方下超过了全 MLA，KV cache 最多省 75%，1M 上下文 decode 吞吐最多 6 倍。两边说法不同，说明这件事还没有定论。

手撕

代码：递推、分块与 Gated Delta

import torch
import torch.nn.functional as F

def linear_attn_recurrent(q, k, v, eps=1e-6):
    # 原版因果线性注意力（带分母）。q, k: [B, H, n, dk]，v: [B, H, n, dv]
    q, k = F.elu(q) + 1, F.elu(k) + 1                        # phi 保证特征为正
    B, H, n, dk = q.shape
    S = q.new_zeros(B, H, v.shape[-1], dk)                   # 状态 [dv, dk]，与 n 无关
    z = q.new_zeros(B, H, dk)
    out = []
    for t in range(n):
        S = S + v[:, :, t, :, None] * k[:, :, t, None, :]     # S += v_t k_t^T
        z = z + k[:, :, t]
        num = (S @ q[:, :, t, :, None]).squeeze(-1)           # S q_t
        den = (z * q[:, :, t]).sum(-1, keepdim=True)          # z^T q_t
        out.append(num / (den + eps))
    return torch.stack(out, dim=2)

def linear_attn_chunk(q, k, v, C=64):
    # 去掉分母的版本（输出后接 RMSNorm），分块并行；结果与逐步递推完全相同
    B, H, n, dk = q.shape
    S = q.new_zeros(B, H, dk, v.shape[-1])                   # 存 S^T = sum k v^T，方便右乘
    mask = torch.ones(C, C, dtype=torch.bool, device=q.device).tril()
    out = []
    for i in range(0, n, C):
        qi, ki, vi = q[:, :, i:i+C], k[:, :, i:i+C], v[:, :, i:i+C]
        c = qi.shape[2]
        inter = qi @ S                                       # 块间：之前所有块的贡献
        A = (qi @ ki.transpose(-1, -2)).masked_fill(~mask[:c, :c], 0)
        intra = A @ vi                                       # 块内：带掩码的 C x C
        out.append(inter + intra)
        S = S + ki.transpose(-1, -2) @ vi                    # 把本块写进状态
    return torch.cat(out, dim=2)

def gated_delta_step(S, q, k, v, alpha, beta):
    # 推理时的一步。S: [B, H, dv, dk]；q, k: [B, H, dk]（已 L2 归一化）；v: [B, H, dv]；alpha, beta: [B, H]
    S = alpha[..., None, None] * S                           # 整体衰减
    v_old = (S @ k[..., None]).squeeze(-1)                   # 记忆里 k 对应的旧值
    S = S + (beta[..., None] * (v - v_old))[..., None] * k[..., None, :]   # 定向改写
    o = (S @ q[..., None]).squeeze(-1)
    return S, o

gated_delta_step 展开就是 St=αtSt−1+βt(vt−αtSt−1kt)kt⊤=αtSt−1(I−βtktkt⊤)+βtvtkt⊤S_t=\alpha_tS_{t-1}+\beta_t(v_t-\alpha_tS_{t-1}k_t)k_t^\top=\alpha_tS_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\topSt​=αt​St−1​+βt​(vt​−αt​St−1​kt​)kt⊤​=αt​St−1​(I−βt​kt​kt⊤​)+βt​vt​kt⊤​。实际训练用 flash-linear-attention 等库的分块 kernel，不会写 Python 循环。

自测

高频追问

线性注意力的核心思想是什么？复杂度怎么降下来的？

把相似度 exp⁡(q⊤k)\exp(q^\top k)exp(q⊤k) 换成可分解的 ϕ(q)⊤ϕ(k)\phi(q)^\top\phi(k)ϕ(q)⊤ϕ(k)，利用矩阵乘法结合律，把 (ϕ(Q)ϕ(K)⊤)V(\phi(Q)\phi(K)^\top)V(ϕ(Q)ϕ(K)⊤)V 改成 ϕ(Q)(ϕ(K)⊤V)\phi(Q)(\phi(K)^\top V)ϕ(Q)(ϕ(K)⊤V)。先算的 ϕ(K)⊤V\phi(K)^\top Vϕ(K)⊤V 只有 d×dd\times dd×d，计算从 O(n2d)O(n^2d)O(n2d) 降到 O(nd2)O(nd^2)O(nd2)，序列长度 nnn 大于 head_dim ddd 时就更省。

为什么 softmax 注意力不能用结合律？

exp⁡(q⊤k)\exp(q^\top k)exp(q⊤k) 不能写成有限维特征的内积，qqq 和 kkk 分不开，只能先算出每一对的分数再归一化。Performer 用随机特征近似 exp⁡\expexp，但要很多特征才准，效果和效率都不理想。

为什么说线性注意力是 RNN？推理时有什么好处？

因果形式下 St=St−1+vtkt⊤S_t=S_{t-1}+v_tk_t^\topSt​=St−1​+vt​kt⊤​、ot=Stqto_t=S_tq_tot​=St​qt​，就是一个以矩阵 StS_tSt​ 为隐状态的 RNN。推理时不存 KV cache，只存大小固定的 StS_tSt​，每个 token 的计算和显存都是 O(d2)O(d^2)O(d2)，与上下文长度无关，长上下文 decode 和大 batch 都受益。

训练时怎么并行？直接用掩码不就行了？

直接写成 (ϕ(Q)ϕ(K)⊤⊙M)V(\phi(Q)\phi(K)^\top\odot M)V(ϕ(Q)ϕ(K)⊤⊙M)V，掩码夹在中间，结合律用不了，又回到 O(n2)O(n^2)O(n2)。逐步递推虽然是线性的，但串行 nnn 步、用不上 Tensor Core。实际用分块算法：块内用带掩码的矩阵乘法，块间传递状态，复杂度 O(nCd+nd2)O(nCd+nd^2)O(nCd+nd2)，串行步数 n/Cn/Cn/C。

线性注意力为什么效果不如 softmax 注意力？

第一，容量：整个历史压进 dk×dvd_k\times d_vdk​×dv​ 的状态，超过 dkd_kdk​ 个 key 后一定相互串扰，纯加法还擦不掉旧内容。第二，检索：大海捞针、MQAR、长文本复制都要原样找回前文，固定大小的状态做不到。第三，注意力不够尖锐：没有 exp⁡\expexp 的放大，权重容易摊平。第四，纯加法分不清远近。

delta rule 是什么？为什么比纯加法好？

把状态 SSS 看成在线学习的线性映射 k↦vk\mapsto vk↦v，每步对 12∥Skt−vt∥2\frac12\lVert Sk_t-v_t\rVert^221​∥Skt​−vt​∥2 做一步梯度下降：St=St−1−βt(St−1kt−vt)kt⊤S_t=S_{t-1}-\beta_t(S_{t-1}k_t-v_t)k_t^\topSt​=St−1​−βt​(St−1​kt​−vt​)kt⊤​。效果是先读出 ktk_tkt​ 对应的旧值，再按 βt\beta_tβt​ 把它替换成 vtv_tvt​，所以同一个 key 写多次不会叠加，记忆不会越堆越乱。纯加法相当于一个没有下界的线性损失，只会一直往里加。

Gated DeltaNet 和 Mamba2、DeltaNet 是什么关系？

Mamba2 给状态乘一个由输入决定的衰减 αt\alpha_tαt​，能整体遗忘，但改不了某一条记忆；DeltaNet 用 delta rule 定向改写，但清空很慢。Gated DeltaNet 把两者合起来：St=αtSt−1(I−βtktkt⊤)+βtvtkt⊤S_t=\alpha_tS_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\topSt​=αt​St−1​(I−βt​kt​kt⊤​)+βt​vt​kt⊤​。Kimi 的 KDA 再把标量 αt\alpha_tαt​ 换成逐维度的向量。

为什么 delta rule 要对 kkk 做 L2 归一化？

∥k∥=1\lVert k\rVert=1∥k∥=1 时，I−βkk⊤I-\beta kk^\topI−βkk⊤ 在 kkk 方向上的特征值是 1−β1-\beta1−β，其余方向是 1，β∈(0,2)\beta\in(0,2)β∈(0,2) 时不会放大状态，递推稳定；而且这时 Stkt=(1−βt)St−1kt+βtvtS_tk_t=(1-\beta_t)S_{t-1}k_t+\beta_tv_tSt​kt​=(1−βt​)St−1​kt​+βt​vt​，βt=1\beta_t=1βt​=1 正好是完全替换。不归一化的话，∥k∥\lVert k\rVert∥k∥ 大时会发散。

线性注意力和 Mamba 这类 SSM 是什么关系？

Mamba2 的 SSD 框架证明，标量衰减的选择性 SSM 和带衰减掩码的线性注意力是同一种计算的两种算法：递推形式像 SSM，并行形式像带掩码的注意力。SSM 的 BtB_tBt​、CtC_tCt​、xtx_txt​ 对应 ktk_tkt​、qtq_tqt​、vtv_tvt​。现在都归为“固定大小状态 + 门控递推”的一类模型。

为什么都用混合架构？比例怎么选？

线性层便宜，能传递压缩后的长程信息，但精确检索弱；少量全注意力层把所有 token 原样存着，负责检索。Qwen3-Next、Qwen3.5、Kimi Linear 是 3:1，MiniMax-01、Jamba 是 7:1。比例越高越省，但检索能力越弱，是各家在实验里权衡出来的。KV cache 只有全注意力层有，3:1 大约降到 1/4。

线性注意力层还需要位置编码吗？

一般不用 RoPE。衰减门让近处的 token 权重更大，本身就带了位置信息，再加一个因果短卷积提供局部顺序。Qwen3-Next 只在全注意力层用 RoPE；Kimi Linear 的 MLA 层也不用位置编码，位置完全交给 KDA。

线性注意力和滑动窗口、稀疏注意力有什么区别？

滑动窗口也只存固定长度的 KV，但窗口外的内容直接丢掉；线性注意力把全部历史压缩进状态，有损但不截断。稀疏注意力（如 NSA、DeepSeek 的 DSA）每个 query 只算一部分 token，省的是计算，KV cache 还是要全部保留。三者常常组合使用。

答题模板

  1. 动机。softmax 注意力训练 O(n2d)O(n^2d)O(n2d)，推理 KV cache 随长度增长、decode 访存受限。
  2. 原理。相似度换成 ϕ(q)⊤ϕ(k)\phi(q)^\top\phi(k)ϕ(q)⊤ϕ(k)，先算 ϕ(K)⊤V\phi(K)^\top Vϕ(K)⊤V，降到 O(nd2)O(nd^2)O(nd2)；因果形式是 RNN：St=St−1+vtkt⊤S_t=S_{t-1}+v_tk_t^\topSt​=St−1​+vt​kt⊤​，推理状态固定。
  3. 训练。直接加掩码会回到平方，用分块算法：块内带掩码并行，块间传状态。
  4. 短板与改进。状态容量有限、只加不减，检索弱；加衰减门（Mamba2、GLA）能遗忘，delta rule 能定向改写，合起来是 Gated DeltaNet。
  5. 落地。混合架构，Qwen3-Next、Qwen3.5、Kimi Linear 3:1，MiniMax-01 7:1；MiniMax-M2 又回到全注意力，说明这个方向还在探索。

常见失分点：说线性注意力是在近似 softmax（现在的做法基本不近似，是另一种机制）；说训练也是 O(1)O(1)O(1)（训练是 O(n)O(n)O(n)，推理每步才是常数）；说加个因果掩码就能并行（会回到平方）；说状态随长度增长；把 Gated DeltaNet 说成 Mamba（核心是 delta rule）；以为用了线性注意力就完全没有 KV cache（混合架构的全注意力层还有）。
