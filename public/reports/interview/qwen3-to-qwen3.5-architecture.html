30 秒背诵版

两条轴：文本 / 多模态 × Dense / MoE；一条主线：降推理成本

Qwen3 的文本模型分 Dense（0.6B–32B）和 MoE（30B-A3B、235B-A22B）两条线。两者共用 GQA + QK-Norm、SwiGLU、RoPE、Pre-RMSNorm，区别只在 FFN 那一格：MoE 是 128 个专家选 8 个，不设共享专家。多模态单独发布了 Qwen3-VL，把 ViT 和 Merger 接到 Qwen3 的 Dense 或 MoE 模型上，新增了 Interleaved-MRoPE 和 DeepStack。

Qwen3-Next 是转折点，只有 MoE、只有文本。注意力改为 Gated DeltaNet 和 Gated Attention 按 3:1 混合，MoE 扩到 512 选 10 加 1 个共享专家，并加入 MTP。

Qwen3.5 把这套混合注意力同时用到 Dense 和 MoE 两条线，而且全系原生多模态，不再单独出 VL 版本。词表扩到 248K。

先分清楚

两条轴：每个模型属于哪一格

Dense 还是 MoE 看 FFN

注意力、Norm、残差、Embedding 都一样，只有 FFN 那一格不同。Dense 让每个 token 都走同一个 SwiGLU FFN。MoE 有一个 Router，每个 token 只走少数几个专家。MoE 的总参数大，但每个 token 的计算量只取决于激活参数。

文本还是多模态 看输入端

多模态模型在输入端多了视觉编码器（ViT）和 Merger，把图像 patch 变成 token 后和文本 token 放进同一个序列，位置编码也要能表示时间、高、宽。Qwen3 时代是在文本模型上再接视觉（Qwen3-VL），Qwen3.5 是从预训练开始就混合训练。

规律：小尺寸用 Dense，部署简单、好微调，也能上端侧；大尺寸用 MoE，用较少的激活参数换更大的总容量。Qwen3 和 Qwen3.5 都是这样分的，Qwen3-Next 只是验证新架构的实验版，所以只出了一个 MoE。

第一代 · 文本基线

Qwen3 文本模型：Dense 和 MoE

2025.04纯文本Dense 0.6B–32B · MoE 30B-A3B / 235B-A22B36T tokens · 119 种语言

Dense 版：0.6B–32B

Dense文本

标准 Decoder 结构

GQA（KV 8 头）+ QK-Norm + RoPE，FFN 用 SwiGLU，Pre-RMSNorm。相比 Qwen2，主要变化是去掉 QKV bias，加入 QK-Norm。

FFN(h) = W_down( SiLU(W_gate·h) ⊙ W_up·h )

小模型共享 Embedding

0.6B、1.7B、4B 让输入 Embedding 和 LM Head 共享权重。词表有 151K，小模型里 Embedding 占的参数比例很高，共享可以省下不少参数。

后训练怎么来

32B 和 235B-A22B 是旗舰，走完整的四阶段：长 CoT 冷启动、推理 RL、思考模式融合、通用 RL。其余尺寸（包括 30B-A3B）用 strong-to-weak 蒸馏，从旗舰模型蒸馏而来，成本低很多。

单模型混合思考

同一个模型用 /think、/no_think 切换思考和非思考，可以设置思考预算。Dense 和 MoE 都是这样。

MoE 版：30B-A3B、235B-A22B

MoE文本

细粒度专家，无共享专家 改动

128 个专家，每个 token 选 8 个。Qwen2-MoE 有共享专家，Qwen3 去掉了，目的是让每个专家学到更有区分度的知识。

global-batch 负载均衡 改动

负载均衡 loss 在整个 global batch 上统计，不在每个 micro-batch 上统计。约束更松，同一领域的 token 可以集中到某些专家，专家分工更明显。

KV 头比 Dense 少

两个 MoE 都只有 4 个 KV 头，Dense 是 8 个。MoE 的总参数大，KV cache 再压一点，长上下文推理时显存压力更小。

部署代价

每个 token 的计算量按激活参数算，但显存要放下全部专家，而且需要专家并行（EP），专家之间有 all-to-all 通信。所以小尺寸更适合 Dense。

第一代 · 多模态

Qwen3-VL：在 Qwen3 上接视觉

2025.09–10图像 + 视频 + 文本Dense 2B / 4B / 8B / 32B · MoE 30B-A3B / 235B-A22B原生 256K，可扩展到 1M

整体结构 多模态DenseMoE

ViT + MLP Merger + Qwen3 LLM。Dense 版（2B/4B/8B/32B）的主干是 Qwen3 Dense，MoE 版（30B-A3B、235B-A22B）的主干是 Qwen3 MoE。LLM 部分的结构和对应的文本模型一样，视觉是在文本模型训练完之后接上的。

Interleaved-MRoPE 改动

Qwen2.5-VL 的 MRoPE 把 RoPE 的维度按块切给时间、高、宽，每个轴只拿到一段频率，频谱不均衡。Qwen3-VL 改成交错分配，每个轴都覆盖高频和低频，长视频理解更好。

DeepStack 改动

以前只用 ViT 最后一层的特征。DeepStack 还取 ViT 中间几层的特征，各自经过 Merger 后加到 LLM 前几层（报告中是前 3 层）的 hidden state 上，保留更多细粒度视觉细节，图文对齐更准。

文本时间戳 改动

视频不再用 T-RoPE 把绝对时间编进位置，而是在帧前面插入文本形式的时间戳 token，比如 <3.0 seconds>，事件的时间定位更准。

Qwen3-Omni（2025.09，30B-A3B）是全模态版本：输入文本、图像、音频、视频，用 Thinker–Talker 两个 MoE 分别负责理解和语音生成，支持流式语音输出。面试中提一句即可。

第二代 · 转折点

Qwen3-Next：混合注意力 + 超稀疏 MoE

2025.09纯文本 · 只有 MoE80B-A3B · 48 层 · hidden 2048原生 262,144，可扩展到约 1M

混合注意力 3:1 核心改动

75% 的层用 Gated DeltaNet。它的状态矩阵 S 大小固定，计算量随序列长度线性增长，也没有不断变大的 KV cache。剩下 25% 的层保留全注意力，用来弥补线性注意力在精确检索（in-context recall）上的不足。

Gated DeltaNet 原理 核心改动

它是 Mamba2 的门控衰减 α 和 DeltaNet 的 delta rule β 的结合。α 控制整体遗忘多少；β 控制先擦掉 k 方向上的旧值，再写入新值，实现定向改写记忆。

S_t = α_t · S_{t−1} (I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ

Gated Attention 输出门 核心改动

在 SDPA 输出后乘一个 sigmoid 门，逐头、逐元素。它在 V 和 O 两个线性投影之间加了非线性，让输出变稀疏并依赖 query，可以消除 attention sink 和 massive activation，训练更稳，长度外推更好。

Y′ = SDPA(Q, K, V) ⊙ σ(X · W_g)

超稀疏 MoE + 共享专家 核心改动

专家从 128 增加到 512，激活 10 个路由专家和 1 个共享专家，激活比例从约 10% 降到约 3.75%。专家变多变窄后，每个专家容量很小，需要共享专家承担通用知识，路由也更稳定。

训练稳定性 改动

Qwen3 的 QK-Norm 中出现过个别 norm 权重异常增大的问题。Next 改成零中心 RMSNorm（权重写成 1 + γ，γ 初始化为 0），并对 γ 加 weight decay，防止它无限变大。Router 参数初始化也做了归一化。

MTP 改动

训练时多预测后续 token，提供更密的监督信号，提升预训练效果。推理时 MTP 头当 draft model，一次猜多个 token，主模型并行验证，不需要另外训练小模型。

官方数据：训练成本不到 Qwen3-32B 的 10%，32K 以上上下文的吞吐约为 Qwen3-32B 的 10 倍。Qwen3-Next 分 Instruct 和 Thinking 两个版本，没有 Dense 版，也没有多模态版。

第三代 · 落地

Qwen3.5：混合注意力用到 Dense 和 MoE，全系原生多模态

2026.02–03全系多模态Dense 0.8B / 2B / 4B / 9B / 27B · MoE 35B-A3B / 122B-A10B / 397B-A17B原生 262,144，可扩展到 1,010,000

原生多模态 改动全系

Qwen3 时代是先训文本模型，再接视觉出 Qwen3-VL。Qwen3.5 在预训练阶段就把视觉 token 和文本 token 交错放进同一个序列一起训练（early fusion）。所以 Qwen3.5 没有单独的 VL 版本，每个尺寸都带视觉编码器。

Dense 也用上混合注意力 改动Dense

Qwen3-Next 只有 MoE。Qwen3.5 的 Dense 模型同样是 3:1 的 Gated DeltaNet + Gated Attention，只是 FFN 位置换成普通 SwiGLU。这说明混合注意力和 Dense / MoE 是两个独立的设计选择。

MoE 配置按尺寸不同 MoE

只有旗舰 397B 用 Next 的 512 选 10 + 1 共享。中尺寸的 122B-A10B 和 35B-A3B 用 256 选 8 + 1 共享。不要说成“Qwen3.5 全系 512 专家”。

KV 头：Dense 4 个，MoE 2 个

全注意力层里，Dense 模型用 4 个 KV 头，MoE 模型用 2 个。和 Qwen3 一样，MoE 的 KV 压得更狠。

词表和语言 改动

词表从 151,669 扩到约 248K（embedding 补齐到 248,320），语言从 119 种扩到 201 种。多语言文本编码效率更高，同样内容需要的 token 更少。

思考模式重新统一 后训练

2507 和 Next 都把 Instruct / Thinking 分成两个模型。Qwen3.5 全系回到一个模型同时支持思考和非思考，后训练重点转向 Agent，在大量环境里做 RL。

自测

高频追问

Dense 和 MoE 有什么区别？Qwen 为什么两条线都做？

结构上只差 FFN 那一格：Dense 每个 token 都走同一个 FFN；MoE 有 Router，每个 token 只激活少数专家。注意力、Norm、Embedding 都一样。

MoE 的好处是总参数（知识容量）大，但每个 token 的计算量只取决于激活参数，同样的训练算力能得到更强的模型。代价是显存要放下所有专家，需要专家并行和 all-to-all 通信，负载均衡也难调。Dense 部署简单、显存小、好微调，适合端侧和中小规模。所以 Qwen3 和 Qwen3.5 都是小尺寸做 Dense，大尺寸做 MoE。

QK-Norm 是什么？为什么用它替代 QKV bias？

QK-Norm 是在 Q、K 投影之后按头做一次 RMSNorm，然后再加 RoPE。

没有 QK-Norm 时，Q·K 的数值可能越训越大，softmax 会饱和成接近 one-hot，梯度变得很差，表现为 loss spike。QK-Norm 把 Q 和 K 的尺度固定住，训练更稳定。QKV bias 在 Qwen2 里主要是为了外推，有了 QK-Norm 之后就不需要了。

为什么 Qwen3 去掉共享专家，Next 又加回来？

Qwen3 有 128 个专家，粒度已经比较细。去掉共享专家可以逼每个专家学到更有区分度的知识，配合 global-batch 负载均衡，专家分工更明确。

Next 扩到 512 个专家，每个专家的中间维度只有 512，单个容量很小。这时需要一个常驻的共享专家承担所有 token 都用得到的通用知识，路由专家专心做专业化，训练也更稳。两次决定是在不同稀疏度下做的取舍，并不矛盾。Qwen3.5 的 MoE 全部保留了共享专家。

Qwen3-VL 的 DeepStack 和 Interleaved-MRoPE 是什么？

DeepStack：普通做法只把 ViT 最后一层的特征喂给 LLM，浅层的细节信息丢了。DeepStack 额外取 ViT 中间几层的特征，各自过一个 Merger，直接加到 LLM 前几层的 hidden state 上。这样 LLM 浅层就能拿到细粒度视觉信息，序列长度也不增加。

Interleaved-MRoPE：多模态位置要表示时间、高、宽三个轴。Qwen2.5-VL 把 RoPE 维度按块切给三个轴，结果某个轴只拿到高频或低频的一段。Qwen3-VL 把三个轴交错分配，每个轴都覆盖全频段，长视频的时间建模更好。视频时间信息则改用文本时间戳 token 表示。

Gated DeltaNet 的原理？和 Mamba2、DeltaNet 是什么关系？

线性注意力可以看作维护一个记忆矩阵 S，每来一个 token 就更新一次，读的时候用 o = S q。

Mamba2 的思路是给 S 乘一个衰减门 α，可以整体遗忘，但不能精确改写某一条记忆。DeltaNet 用 delta rule：先把 k 方向上的旧值擦掉，再写入新值，强度由 β 控制，可以精确改写，但不能快速清空。Gated DeltaNet 把两者结合：

S_t = α_t · S_{t−1} (I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ

实现上 q、k、v 先过因果卷积和 SiLU，q、k 做 L2Norm，输出再乘一个 SiLU 门。训练时用分块并行算法，推理时是 O(1) 的递推。

为什么不全部换成线性注意力？3:1 是怎么来的？

线性注意力把整段历史压进一个固定大小的状态，信息必然有损失。在需要精确找回前文某个细节的任务上（大海捞针、in-context recall、多跳检索），它明显不如全注意力。

所以采用混合方案：大部分层用线性注意力，低成本地传递长程信息；少量全注意力层负责精确检索。3:1 是官方实验下来效果和效率比较平衡的比例，Qwen3.5 从 9B 到 397B 都沿用了这个比例。类似的混合方案还有 Kimi Linear、MiniMax 的 Lightning Attention、Jamba 等。

Gated Attention 的门加在哪？解决什么问题？

门加在 SDPA 输出之后、W_o 之前，形式是 Y ⊙ σ(X W_g)，逐头、逐元素。它的输入是当前 token 的 hidden state，所以门的值依赖 query。

作用有三点。第一，W_v 和 W_o 原本都是线性变换，合起来是一个低秩的线性映射，中间加了门就有了非线性。第二，门让输出稀疏，模型不必把注意力堆到第一个 token 上当垃圾桶，attention sink 和 massive activation 因此消失。第三，训练更稳定，可以用更大的学习率，长度外推也更好。相关论文拿了 NeurIPS 2025 最佳论文。

MTP 在训练和推理时分别起什么作用？

训练时，除了预测下一个 token，还用额外的模块预测后面第二个、第三个 token。这给了更密的监督信号，迫使表示提前规划，可以提升预训练效果。

推理时，MTP 模块就是现成的 draft model：它先猜出后面几个 token，主模型一次前向并行验证，猜对的直接接受。这样不需要另外训练一个小模型，就能做投机解码。vLLM 和 SGLang 都已支持。

思考模式为什么拆开又合起来？

Qwen3 一开始用单模型混合思考。2507 版本拆开，官方说法是混合训练会让两种模式的效果互相拖累，拆开后各自都更强。

Qwen3.5 又回到统一。官方没有详细解释原因，可以这样回答：后训练的数据配比和 RL 方法改进后，冲突问题得到缓解，统一模型在部署上更省事，只需维护一套权重。回答时要说明这是自己的推断。

零中心 RMSNorm 加 weight decay 解决什么问题？

普通 RMSNorm 的缩放权重 γ 初始化为 1。如果对它做 weight decay，它会被往 0 拉，这显然不对，所以一般不加。Qwen 团队发现 QK-Norm 里个别 γ 会异常增大，影响稳定性。

零中心的做法是把权重写成 1 + γ，γ 初始化为 0。这样 weight decay 会把它拉回 1 附近，正好约束了异常增长。

原生多模态（Qwen3.5）和后接视觉（Qwen3-VL）有什么区别？

Qwen3-VL 的做法是：先有训练好的 Qwen3 文本模型，再接 ViT 和 Merger，经过对齐和多模态继续训练。视觉能力是后加的，文本和多模态要维护两套模型，而且继续训练可能会损失一些文本能力。

Qwen3.5 在预训练阶段就把图像 token 和文本 token 交错放在同一个序列里训练。视觉和语言在同一个表示空间里学，一个模型就够了，对 Agent 场景（看截图、操作界面）更友好。

2–3 分钟口述

答题模板

  1. 先给分类框架。每一代都从两条轴看：文本还是多模态，Dense 还是 MoE。主线是降低推理成本，以及从“后接视觉”走向原生多模态。
  2. 讲 Qwen3 文本模型。Dense 和 MoE 共用 GQA + QK-Norm、SwiGLU、RoPE、RMSNorm；MoE 只在 FFN 位置换成 128 选 8、无共享专家。单模型混合思考。
  3. 讲 Qwen3-VL。ViT + Merger 接在 Qwen3 Dense 或 MoE 上，新增 Interleaved-MRoPE、DeepStack、文本时间戳。
  4. 讲 Next 的转折。只有 MoE、纯文本。3:1 混合注意力及原因、Gated Attention 输出门、512 选 10 + 1 共享、MTP。可以顺手报出 KV cache 估算的量级。
  5. 讲 Qwen3.5 落地。混合注意力同时用到 Dense 和 MoE；全系原生多模态，不再单出 VL；词表 248K、201 种语言；思考模式重新统一。
  6. 给出判断。竞争重点从堆参数转向单位推理成本下的能力。长上下文和 Agent 让 KV cache 成为瓶颈，各家都在做稀疏注意力或线性注意力，只是取舍不同。

常见失分点：说 Qwen3 有共享专家（没有）；说 Qwen3-Next 有 Dense 或多模态版（都没有）；说 Qwen3.5 全系都是 512 专家（只有 397B 是，中尺寸 MoE 是 256 选 8）；以为 Qwen3.5 Dense 还是标准全注意力（也是 3:1 混合）；把 Gated DeltaNet 说成 Mamba（它借鉴了 Mamba2 的门控，但核心是 delta rule）；把 Gated Attention 的门说成加在 softmax 之前（实际在 SDPA 输出之后）。拿不准的数字就说量级。
