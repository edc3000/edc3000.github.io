先给结论

30 秒背诵版

注意力本身不认顺序 → 需要位置编码；主流是 RoPE：把 Q、K 按位置旋转，内积只剩相对位置

为什么需要：自注意力对输入顺序是置换等变的，不加位置信息，“我打你”和“你打我”只差一个排列。早期做法是把位置向量加到输入上（Sinusoidal、可学习的绝对位置），后来改成在注意力里注入相对位置（T5 bias、ALiBi、RoPE）。

RoPE：把 qqq、kkk 的 ddd 维两两分成 d/2d/2d/2 个二维平面，第 iii 个平面按位置 mmm 旋转角度 mθim\theta_imθi​，θi=base−2i/d\theta_i=\text{base}^{-2i/d}θi​=base−2i/d。因为 Rm⊤Rn=Rn−mR_m^\top R_n=R_{n-m}Rm⊤​Rn​=Rn−m​，旋转后的内积只依赖相对位置 n−mn-mn−m。不加参数、只作用在 Q、K、每层都做，兼容 KV cache。

频率：前面的维度转得快（波长约 6），管局部；后面的转得慢（波长可达几万），管长距离。base 越大，最慢的维度越慢，能区分的距离越远，所以长上下文模型把 base 从 1 万调到 50 万、100 万。

外推：超过训练长度时，低频维度会转到训练时没见过的角度，效果崩掉。PI 把所有位置等比压缩，NTK 改 base 只压低频，YaRN 按维度分段：高频不动、低频插值、中间平滑过渡，再给注意力 logits 乘一个温度。

动机

为什么需要位置编码

注意力不认顺序 核心原因

注意力分数 qm⊤knq_m^\top k_nqm⊤​kn​ 只看两个 token 的内容，不看它们在哪。把输入打乱，每个 token 的输出也只是跟着打乱，这叫置换等变。没有位置信息，模型就是一个“词袋”。

因果掩码也带一点位置 加分项

decoder 有因果掩码，第 mmm 个 token 只能看到前 mmm 个，所以理论上能从“能看到多少东西”推断出绝对位置。有研究（NoPE）发现完全不加位置编码的 decoder 也能训，长度泛化甚至不差。但主流模型仍然用显式位置编码，效果更稳定。

局限

位置向量是加到词向量上的，进入注意力前还要乘 WQW_QWQ​、WKW_KWK​，展开后内积里混着“内容 × 位置”的交叉项，相对位置的性质并不能干净地保留下来。实际外推也不好。

RoPE 的想法正是：别加，直接在 Q、K 上做旋转，让相对位置在内积里精确成立。

主角

RoPE：旋转 Q 和 K，内积只剩相对位置

目标：找一个作用在 qqq、kkk 上的变换 fff，使旋转后的内积只依赖内容和相对位置：

⟨f(q,m), f(k,n)⟩=g(q,k, n−m)\big\langle f(q,m),\,f(k,n)\big\rangle=g(q,k,\,n-m)⟨f(q,m),f(k,n)⟩=g(q,k,n−m)

二维情况下，答案就是旋转：f(x,m)=Rmxf(x,m)=R_m xf(x,m)=Rm​x，RmR_mRm​ 是旋转 mθm\thetamθ 角的矩阵。因为旋转矩阵满足 Rm⊤Rn=Rn−mR_m^\top R_n=R_{n-m}Rm⊤​Rn​=Rn−m​：

(Rmq)⊤(Rnk)=q⊤Rm⊤Rn k=q⊤Rn−m k,Rm=(cos⁡mθ−sin⁡mθsin⁡mθcos⁡mθ)(R_m q)^\top(R_n k)=q^\top R_m^\top R_n\,k=q^\top R_{n-m}\,k,\qquad R_m=\begin{pmatrix}\cos m\theta&-\sin m\theta\\ \sin m\theta&\cos m\theta\end{pmatrix}(Rm​q)⊤(Rn​k)=q⊤Rm⊤​Rn​k=q⊤Rn−m​k,Rm​=(cosmθsinmθ​−sinmθcosmθ​)

推广到 ddd 维：把向量两两分组成 d/2d/2d/2 个二维平面，每个平面用自己的角速度 θi\theta_iθi​ 旋转，整体是一个分块对角的旋转矩阵：

RΘ,m=diag(R(mθ0), R(mθ1), …, R(mθd/2−1)),θi=base−2i/d,  base=10000R_{\Theta,m}=\mathrm{diag}\big(R(m\theta_0),\,R(m\theta_1),\,\dots,\,R(m\theta_{d/2-1})\big),\qquad \theta_i=\text{base}^{-2i/d},\ \ \text{base}=10000RΘ,m​=diag(R(mθ0​),R(mθ1​),…,R(mθd/2−1​)),θi​=base−2i/d,  base=10000

几个关键性质 常考

  • 相对位置：用绝对位置 mmm 做旋转，内积却只依赖 n−mn-mn−m。
  • 只作用在 Q、K：位置只需要影响“谁和谁相关”，V 是被搬运的内容，不需要旋转。
  • 每层都做：在每一层注意力里、投影之后旋转，而不是只在输入加一次。
  • 无参数、保范数：旋转不改变向量长度。
  • 兼容 KV cache：K 按自己的位置旋转一次后缓存，新 token 只需旋转自己的 Q、K。

远程衰减 常被追问

RoPE 论文证明，在 qqq、kkk 固定的情况下，内积的上界会随相对距离 ∣n−m∣|n-m|∣n−m∣ 增大而平均意义上衰减（有振荡）。直觉是：距离越远，各个平面的旋转角度越“错开”，相加时互相抵消得越多。

这符合“越近越相关”的先验。base 越大，转得越慢，衰减也越慢，长距离的 token 更不容易被“忘掉”。

高频维度管局部，低频维度管远距离

波长只有 6 的维度，相邻 token 的角度差很大，能精确区分“前一个还是前两个”；但距离一远就转了很多圈，分不清 100 和 106。波长几万的维度正相反，适合分辨远距离，局部上几乎不动。

base 调大意味着什么

base 越大，所有维度（除了第 0 对）都转得更慢，最慢的维度波长变长，能区分的最大距离变大，远程衰减也更慢。所以长上下文模型普遍调大 base：LLaMA 3 用 500,000，Qwen3 用 1,000,000。在继续预训练时调大 base 来扩上下文，叫 ABF（adjusted base frequency）。

新模型

新模型里的 RoPE 变体

Partial RoPE Qwen3-Next、GPT-NeoX

只旋转一部分维度，其余维度不加位置信息。Qwen3-Next 的全注意力层 head_dim 为 256，只有 64 维用 RoPE。不旋转的维度做纯语义匹配，不受远程衰减影响，对长上下文更友好。

解耦 RoPE DeepSeek MLA

MLA 把 K 压缩成低秩向量，推理时要把上投影矩阵吸收进 Q 的投影里。但 RoPE 的旋转矩阵随位置变化，夹在中间就没法吸收。所以 DeepSeek 单独拿出一小段维度（每头 64 维）带 RoPE，K 的这一段所有头共享，和不带位置的压缩部分拼起来。

M-RoPE Qwen2-VL、Qwen3-VL

图像和视频的位置是三维的（时间、高、宽）。把 RoPE 的维度分给三个轴，各自按自己的坐标旋转；文本 token 三个坐标相同，退化成普通 RoPE。Qwen3-VL 改成交错分配，让每个轴都覆盖全频段，见 Qwen3 → Qwen3.5 架构演进。

部分层不加位置编码 NoPE 交错

一些模型（如 Llama 4 的 iRoPE）每隔几层放一层不加位置编码的全局注意力，其余层用 RoPE。不加位置的层不存在“没见过的角度”，有利于长度泛化。

代码：RoPE 的高效实现

不用真的构造分块旋转矩阵。对每一对 (x1,x2)(x_1,x_2)(x1​,x2​)，旋转后是 (x1cos⁡φ−x2sin⁡φ, x2cos⁡φ+x1sin⁡φ)(x_1\cos\varphi-x_2\sin\varphi,\ x_2\cos\varphi+x_1\sin\varphi)(x1​cosφ−x2​sinφ, x2​cosφ+x1​sinφ)，可以写成逐元素运算：

RΘ,m x=x⊙cos⁡(mΘ)+rotate_half(x)⊙sin⁡(mΘ)R_{\Theta,m}\,x=x\odot\cos(m\Theta)+\mathrm{rotate\_half}(x)\odot\sin(m\Theta)RΘ,m​x=x⊙cos(mΘ)+rotate_half(x)⊙sin(mΘ)
def rope_cache(T, d, base=10000.0):
    inv_freq = base ** (-torch.arange(0, d, 2).float() / d)   # [d/2]，θ_i
    pos = torch.arange(T).float()                             # PI：pos / s；NTK：换 base
    freqs = torch.outer(pos, inv_freq)                        # [T, d/2]，m·θ_i
    emb = torch.cat([freqs, freqs], dim=-1)                   # [T, d]，前后两半配对
    return emb.cos(), emb.sin()

def rotate_half(x):
    x1, x2 = x[..., : x.shape[-1] // 2], x[..., x.shape[-1] // 2 :]
    return torch.cat([-x2, x1], dim=-1)

def apply_rope(q, k, cos, sin):                                # q, k: [B, H, T, d]
    return q * cos + rotate_half(q) * sin, k * cos + rotate_half(k) * sin

# 推理时：cos/sin 按“KV cache 已有长度 + 当前偏移”取对应位置；缓存的是旋转后的 K

配对方式有两种：原论文和 Meta 的复数实现是相邻两维 (2i,2i+1)(2i,2i+1)(2i,2i+1) 配对；HuggingFace 的 rotate_half 是第 iii 维和第 i+d/2i+d/2i+d/2 维配对。两者数学上等价，只是维度顺序不同，HF 在转换 LLaMA 权重时对 WQW_QWQ​、WKW_KWK​ 的行做了重排。自己写实现或转换权重时，配对方式必须和权重一致，否则结果全错。

自测

高频追问

为什么 Transformer 需要位置编码？

自注意力的分数只取决于两个 token 的内容，对输入排列是置换等变的，打乱顺序输出也只是跟着打乱，模型分不出“我打你”和“你打我”。位置编码把顺序信息注入进去。decoder 的因果掩码会带来一点隐式的位置信息，但显式位置编码更稳定。

绝对位置编码和相对位置编码有什么区别？

绝对位置编码给每个位置一个向量，加到输入上（Sinusoidal、BERT 的可学习位置），模型要自己从中推出相对关系，而且超过训练长度没法用。相对位置编码直接在注意力里体现两个 token 的距离（T5 bias、ALiBi、RoPE），更符合语言“看相对距离”的特点，外推也更好。RoPE 比较特殊：实现上用的是绝对位置，效果上是相对位置。

RoPE 的原理是什么？为什么能表示相对位置？

把 qqq、kkk 两两分组成二维平面，按位置 mmm 旋转 mθim\theta_imθi​。旋转矩阵满足 Rm⊤Rn=Rn−mR_m^\top R_n=R_{n-m}Rm⊤​Rn​=Rn−m​，所以 (Rmq)⊤(Rnk)=q⊤Rn−mk(R_mq)^\top(R_nk)=q^\top R_{n-m}k(Rm​q)⊤(Rn​k)=q⊤Rn−m​k，注意力分数只依赖相对位置 n−mn-mn−m。不同平面用不同频率 θi=base−2i/d\theta_i=\text{base}^{-2i/d}θi​=base−2i/d，组合起来既能分辨近距离也能分辨远距离。

RoPE 为什么只加在 Q、K 上，不加在 V 上？

位置要影响的是“哪些 token 之间更相关”，也就是注意力分数 q⊤kq^\top kq⊤k，旋转 Q、K 就够了。V 是被加权求和的内容，旋转 V 会把位置混进输出表示，而且不再保持“只依赖相对位置”的性质。

RoPE 的远程衰减是什么？

RoPE 论文证明，固定 qqq、kkk 时，内积的上界随相对距离增大而平均衰减（有振荡）。距离越远，各平面的旋转越错开，求和时相互抵消。这符合“越近越相关”的语言先验。base 越大衰减越慢。

base 越大意味着什么？为什么新模型都调大 base？

θi=base−2i/d\theta_i=\text{base}^{-2i/d}θi​=base−2i/d，base 越大，除第 0 对外所有维度转得越慢，最长波长从约 5 万（base 1 万、d=128d=128d=128）变成几百万（base 50 万）。训练时就能覆盖更长的距离，远程衰减更慢，所以长上下文模型普遍调大 base（LLaMA 3 用 50 万，Qwen3 用 100 万）。代价是近距离的分辨率会稍降，需要配合足够长的训练数据。

直接外推为什么会崩？PI、NTK、YaRN 有什么区别？

波长超过训练长度的低频维度，在训练时连一圈都没转完；推理更长时会转到没见过的角度，注意力分数分布异常。

PI：所有位置等比例压缩 sss 倍，不越界，但高频维度分辨率也降了，需要微调。NTK-aware：把 base 换成 base⋅sd/(d−2)\text{base}\cdot s^{d/(d-2)}base⋅sd/(d−2)，高频几乎不动，最低频压缩 sss 倍，不微调也能用。YaRN：按每个维度在训练长度内转了几圈分段处理，高频不动、低频完全插值、中间线性过渡，并加注意力温度，效果最好，用少量数据微调即可。

YaRN 为什么要加温度系数？

上下文变长后，同一个 query 要在更多 key 上分配注意力，softmax 分布变平、熵变大，注意力不够集中。YaRN 把 logits 乘以 1/t1/t1/t，1/t=0.1ln⁡s+1\sqrt{1/t}=0.1\ln s+11/t​=0.1lns+1，让分布重新变尖。实现上把 cos、sin 都乘以 1/t\sqrt{1/t}1/t​，相当于 q⊤kq^\top kq⊤k 乘了 1/t1/t1/t。

DeepSeek 的 MLA 为什么要解耦 RoPE？

MLA 推理时把 K 的上投影矩阵吸收进 Q 的投影，只缓存低秩的压缩向量。RoPE 的旋转矩阵依赖位置，夹在 WQW_QWQ​ 和 WUKW_{UK}WUK​ 之间，矩阵乘法不能交换，吸收不了。解决办法是单独拿一小段维度带 RoPE（每头 64 维，K 的这段所有头共享并直接缓存），其余维度不带位置、照常压缩和吸收，两段拼起来算注意力。

ALiBi 和 RoPE 怎么比？

ALiBi 在注意力 logits 上加 −mh ∣i−j∣-m_h\,|i-j|−mh​∣i−j∣，每个头一个固定斜率，距离越远惩罚越大。实现简单、外推好，但它是硬性的线性衰减，远距离信息被强压，长上下文检索能力受限。RoPE 表达能力更强，配合 base 调整和 YaRN 后长上下文效果更好，所以成了主流。

多模态模型的位置编码怎么做？

图像有高、宽两个轴，视频还有时间轴。M-RoPE 把 RoPE 的维度分给时间、高、宽三个轴，每段按对应坐标旋转；文本 token 三个坐标相同，退化成普通 RoPE。Qwen3-VL 的 Interleaved-MRoPE 把三个轴交错分配维度，避免某个轴只拿到高频或低频的一段。

实现 RoPE 时有哪些坑？

配对方式（相邻两维还是前后两半）必须和权重一致；cos、sin 的缓存要用 float32 计算，位置很大时低精度会算不准角度；推理时位置要加上 KV cache 已有的长度；缓存的是旋转后的 K；用 PI 或 NTK 时要和训练、微调时的设置完全一致。

2 分钟口述

答题模板

  1. 先讲为什么。自注意力置换等变，不认顺序，需要注入位置信息。
  2. 讲演进。Sinusoidal 和可学习的绝对位置加在输入上；T5 bias、ALiBi 在注意力里加相对位置；RoPE 旋转 Q、K，是目前的主流。
  3. 讲 RoPE。两两分组成二维平面，按 mθim\theta_imθi​ 旋转，Rm⊤Rn=Rn−mR_m^\top R_n=R_{n-m}Rm⊤​Rn​=Rn−m​，内积只依赖相对位置；只作用于 Q、K，每层都做，无参数，兼容 KV cache，有远程衰减。
  4. 讲频率和 base。θi=base−2i/d\theta_i=\text{base}^{-2i/d}θi​=base−2i/d，高频管局部、低频管远距离；base 越大最长波长越长，长上下文模型普遍调大 base。
  5. 讲外推。低频维度没转完一圈就越界；PI 全部压缩，NTK 改 base，YaRN 按维度分段并加温度。最后可以提 MLA 的解耦 RoPE、Partial RoPE、M-RoPE。

常见失分点：说 RoPE 加在输入上（是每层的 Q、K 上）；说 RoPE 也旋转 V（不旋转）；说 base 越大越能分辨近距离（反了）；说 PI 不需要微调（通常要少量微调，NTK 才号称免微调）；把 θi\theta_iθi​ 写成 base2i/d\text{base}^{2i/d}base2i/d（是负指数）。
