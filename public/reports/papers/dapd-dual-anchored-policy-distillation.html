核心结论

  1. On-policy 自蒸馏（OPSD）让模型对着参考答案给自己当 teacher，学生推理时却看不到这份答案——结果学生学会了装作记得，训练越久越严重。
  2. 这篇论文把病因指向 信息不对称：teacher 有特权信息、学生没有，那条蒸馏项就把「学生能复现的指导」和「依赖特权的行为」一起灌了进去。
  3. 解法不是削弱 teacher，而是补一个既可训练、又和 teacher 信息对等的中间分布当桥。Qwen3-4B 六项基准平均 +2.00；更关键的是规模越大优势越明显——32B 上 OPSD 的增益几乎归零，DAPD 仍有 +3.06。

01模型说它「记得」这道题的答案

同一个模型、同一道题、同一套解码设置，两种训练方法给出的不是同一种错法。

先看一道 AIME24 的圆环几何题：一个大半径 6、小半径 3 的圆环，与一个半径 11 的球相切，求 ri − ro = m/n 时的 m+n。正确答案是 127。

OPSD 训出来的模型
推导走进死胡同之后
「…外切情形下距离是 6+2*6=18，于是 r=√(11²−18²)，是虚数，不可能。…
我确实卡住了，只能放弃，但
我记得答案大概是 36/7。
所以 m+n = 36+7 = 43。」
✗ 答 43
DAPD 训出来的模型
从题目本身推到底
「情形一：内切。…√(6²+c²)=11−3=8，… Px=33/4。
外切时，两心距离为 11+3=14，… Px=33/7。
所以 ri−ro = 33/4 − 33/7 = 99/28。… m+n = 127。」
✓ 答 127

值得停下来看的不是谁答对了，而是左边那句「我记得答案大概是 36/7」。模型手上没有任何东西支撑这个数字：它推导失败了，题面里也没有答案。可它写得像是想起了什么，然后照着这个凭空的数字把后续步骤补完。

这个行为有名字——特权幻觉（privilege illusion）。它不是一般意义上的幻觉，而特指一类成因：训练时看得到、推理时看不到。训练的时候，它的 teacher 真的看得见答案。

论文为此定义了一个行为探针 wrong claims（错误断言）：模型宣称一个没有推导支撑的答案，再倒过来编一段推导。用它去追踪 OPSD 的训练过程，能看到两条同向移动的曲线：

13.0 → 37.0
OPSD 训练中每一万次生成里的错误断言数，五个 Qwen3 规模上的平均
59.56 → 53.24
同一时期的推理均分（AIME24 / AIME25 / HMMT25 上的 Avg@12）

幻觉涨上来的同时，成绩掉下去。也就是说，OPSD 这套「让 teacher 更强」的做法，训练到后期是在主动损害推理表现的。这篇论文要回答的就是：既然 teacher 更强了，为什么学生反而更差？

02OPSD 是怎么把参考答案变成 teacher 的

先把这套做法讲清楚，后面的诊断才有落点。

OPSD 的出发点相当合理。相比 SFT（喂固定演示）和 RL（稀疏的结果奖励），on-policy 蒸馏的优势是在学生自己走出来的状态上、给 token 级的稠密监督。但要有稠密监督就得有个 teacher，而另找一个更大的 teacher 模型既贵又有分布不匹配的麻烦。

OPSD 的办法是不换模型，只让同一个模型多看一样东西：这道题的参考解答。做法很直白——把参考解答原文塞进 teacher 那一侧的 user message：

None view（学生看到的）
Problem: {problem} Please reason step by step, and put your final answer within \boxed{}.
Cross view（teacher 看到的）
Problem: {problem} Here is a reference solution to this problem: === Reference Solution Begin === {reference completion} === Reference Solution End === After reading the reference solution above, make sure you truly understand the reasoning behind each step — do not copy or paraphrase it. Now, using your own words and independent reasoning, derive the same final answer…

所谓特权信息，就是这两个分隔符之间的一整段明文。注意它是什么、不是什么：它不是一个额外的标签，也不是什么隐藏的 teacher 内部状态，就是一段完整的、人类可读的解题过程。它只在构造训练分布时出现，从不进推理 prompt。

▸ 一个真实的训练样本长什么样 OpenThoughts 里的一道幂次比大小题，看看「特权信息」具体是哪几行字

题目要求给 p = 23009、q = 32006、r = 51003 排序。参考解答把三者改写成同底次幂 81003、91003、51003，于是 r < p < q。

在这个样本上：None 的 message 只有题面和作答要求；Cross 和 Self 的 message 把上面这段完整推导塞进两个分隔符之间。

所以「特权信息」是一段写明白的解题过程——teacher 不是模糊地「更聪明」，而是字面意义上已经看过怎么做了。

剩下的就是标准蒸馏。设当前学生策略为 pθ，从它采一条 on-policy rollout y，然后在 y 的每个前缀上让同一个模型算两次：

None 分布 p_None = p_θ(· | x, y_<t) ← 只给题面和已生成的前缀 Cross 分布 p_Cross = p_θ(· | x, y_<t, y*) ← 额外给完整参考解答 y*

把 Cross 停梯度当 teacher，去教 None：

LOPSD = 𝔼(x,y*)~D, y~pθ(·|x) [ (1/|y|) Σt D( sg[pCross] ‖ pNone ) ] sg[·] 表示停梯度；D 是 token 分布之间的散度

于是 teacher 更强（它看得见答案），学生仍然在自己的分布上被训练。看起来两全其美——而第 01 节那句「我记得」就是这个设计的账单。

03问题不在 teacher 不够好，在两边看到的信息不一样

已有的两派修法都在改信号，而没有改信息。

在这篇论文之前，针对特权幻觉的工作大致分两派：

  • 直接使用特权监督（OPSD、SDFT、SDPO）——照单全收 teacher 的完整信号；
  • 选择性转移（Purified OPSD、DOPD 等）——过滤或重加权 teacher 信号，试图压掉那些依赖特权的部分。

两派都没修干净。论文的判断是：这个局限是结构性的。它们改的是特权 teacher 发出的信号，而不是让 teacher 和学生看到的信息一样。只要一个有特权的 teacher 还在监督一个没有特权的学生，那条监督里就同时含着两种东西：

  • 学生能从自己的 prompt 复现出来的指导——这部分有用；
  • 只有靠 y* 才能得到、学生推理时根本不可能复现的行为——这部分就是毒。

论文把这种混在一起的更新叫 Entangled Distillation（纠缠蒸馏）。「纠缠」二字解释了为什么过滤和路由都不彻底：你没法在信号层面可靠地把这两种东西切开，因为它们是同一个前向过程的产物。

一个只改学生端的对照实验

为了验证这个诊断，论文做了一次很干净的干预：teacher 那边一个字不改，只把学生端的 None 换成一个新分布 —— Self，它条件在它正在预测的那条完整 completion 上。

原来 D( sg[p_Cross] ‖ p_None ) teacher 有特权，学生没有 → 信息不对称 换成 D( sg[p_Cross] ‖ p_Self ) 两边都拿到一份完整 completion → 信息对等

这样一来 Cross 和 Self 都拿到了一份完整的 completion，teacher 和学生之间的信息落差就被抹平了。论文把这个目标称作 Privileged Anchor（特权锚）。结果：

−45%
训练后期的错误断言数（相对 OPSD）
+6.22
推理 Avg@12 的平均提升
这个实验为什么关键

teacher 的构造完全没动——同一个模型、同一段参考解答、同一个 detach。光是把学生端的信息条件拉平，就换来了这么大的改善。所以病根是信息不对称本身，而不是 teacher 质量。

顺带地，这个实验也交出了后面整套方法的关键零件：Self 这个分布。下一节的全部内容，都是围绕怎么把它用好。

04补一个能被训练的中间分布

DAPD 的两层锚定：先让信息对等（双路径），再让指导源互补（双源）。

先把三个分布并排放一次。它们共享同一个自回归前缀 s<t，区别只在额外条件是什么。这里 s 可以是 rollout y，也可以是参考解答 y*，s̄ 指另一条。

分布条件额外看到什么能否被训练推理时存在吗
Nones pθ(· | x, s<t) 什么都没有 ✅ 可训练 ✅ 就是推理时那个
Crosss pθ(· | x, s<t, s̄) 另一条 completion ❌ 停梯度，当 teacher ❌
Selfs pθ(· | x, s<t, s) 自己这条 completion ✅ 可训练 ❌

Self 看起来有点古怪——它在预测 s 的同时，条件里就摆着完整的 s。但这正是它有用的原因，把最后两列连起来读就明白了：

  • 跟 Cross 比，Self 是可训练的——它和 None 共享同一份参数，梯度穿过 Self 就是在改那个推理时真正会跑的策略；
  • 跟 None 比，Self 是信息对等的——它和 Cross 一样都拿到了一份完整 completion。

换句话说，Self 恰好补上了原本空着的那个位置：介于「没有特权的可训练学生」和「有特权的停梯度 teacher」之间。整篇论文的支点就在这里。

方法总览

把这个零件装进完整框架，就是下面这张图。左边是双源锚定的全景，右边把其中一个方向拆开看。

▸ 展开图解说明 逐个模块讲清楚：左右两块分别在说什么，每种箭头代表哪条 loss，中间那个红叉是什么意思
  • 左半张：双源锚定（Dual-Source Anchoring）的全景。两团等高线代表两个策略分布——青色是以参考解答为条件的 Teacher Policy y*，橙色是学生自己的 Student Policy y。中间那个点是训练要收敛到的目标策略。两条弧线是两个引导方向：青色的「Reference TO Rollout」用参考去引导轨迹，橙色的「Rollout TO Reference」反过来。两条都保留，这就是「双源」。
  • 右半张：把「轨迹→参考」这一个方向放大。图中每条小曲线都是一个 token 级分布，下面标注了它的条件。三行内容对应两条路径。
  • 粉色虚线双箭头 = 无条件路径（Unconditioned Path）。顺着看是一条链：最左 y ~ pNoney = pθ(·|x)，经 Lenty 指向中间那条既是 pCrossy 又是 pSelfy* 的分布（它们都条件在 x, y* 上，所以画成同一条），再经 Linfery* 指向最右的 pNoney*。顶部的 Luncondy→y* = Lenty + Linfery* 就是这条链的和。
  • 中间的虚线框 Pself 和红叉。红叉标着「OPSD ✗ Information asymmetry」，意思是 OPSD 想直接从有特权的一侧跨到无特权的一侧，而这一跳正是信息不对称发生的地方。DAPD 不走这一跳，改为从 Pself 分出 y 和 y* 两支绕过去。
  • 蓝色实线箭头 = 特权路径（Privileged Path）。底部一行：y ~ pSelfy = pθ(·|x, y) 经 Lprivy 指向 y ~ pCrossy = pθ(·|x, y*)。两端都拿到了一份完整 completion，信息对等，所以可以直接对齐。

一句话总结：右边讲的是同一个方向上「两条路径怎么配合」，左边讲的是「这套配合要在两个方向上各做一次」。

三个定向目标

在讲路径之前，先把积木摆出来。对每个 completion 源 s，DAPD 定义三个有方向的目标——停梯度的那个是 teacher，另一个是被训练的学生：

目标形式teacher → 学生它负责什么
纠缠蒸馏
Lents		 D( sg[Crosss] ‖ Nones ) Cross → None 就是 OPSD 原来那一项。DAPD 保留了它，不是删掉——它仍然携带着有用的参考指导
推理锚
Linfers		 D( sg[Nones] ‖ Selfs ) None → Self 把 Self 拉向「没有特权时的样子」，为无条件路径提供锚点
特权锚
Lprivs		 D( sg[Crosss] ‖ Selfs ) Cross → Self 两边都有特权时的直接对齐，就是第 03 节那个对照实验里的目标

注意两个锚的学生端永远是 Self。Self 被两股力量同时拉扯——一边拉向无特权的 None，一边拉向有特权的 Cross。这个拉扯正是「桥」的物理含义。

双路径锚定：怎么让两个 None 对齐

特权路径好理解：Cross 和 Self 都拿到完整 completion，信息对等，直接用 Lprivs 对齐就行，不需要新目标。

真正巧妙的是无条件路径。它想要的是让两个 None 对齐——它们都不带特权信息，都是推理时真正会出现的分布。可按定义，这两个分布压根不跑在同一组 token 上——一个在 y 的位置上，另一个在 y* 的位置上，没有逐 token 的对应关系可以直接算散度。DAPD 于是用两项组合出这个效果：

双源锚定：谁来当指导源

双路径解决的是「一个有向组合内部怎么对齐」。剩下的问题是方向本身：该让谁引导谁？

两个候选各有各的毛病，而且毛病正好互补：

参考解答 y*
Reference

可靠——它是对的，携带明确的正确性信号。但它可能落在当前策略够不着的地方，属于 off-policy。

自采样轨迹 y
Rollout

够得着——它就是学生自己走出来的，天然 on-policy。但它可能是错的，尤其在小模型上。

论文的选择是两个都要，用 λ 配比：

LDAPD = λ · LDPAy→y* + (1−λ) · LDPAy*→y λ ∈ [0,1]，越大越倚重参考解答的引导

这里有个容易忽略的转念：在 OPSD 的框架里，rollout 只是被预测的对象；而 DSA 让它也成为引导源。理由是模型变强之后，它自己走出来的轨迹里本来就含有有用的推理和自我纠错——一直只拿参考答案当唯一权威，是在浪费这部分信号。第 05 节会看到，这个转念在大模型上收益最明显。

▸ 一个 minibatch 实际怎么跑 五步训练流程，以及三种 teacher 分别来自哪份参数——这里有个容易看漏的细节
1. 用当前带 LoRA 的学生，为每个 (x, y*) 采一条 on-policy rollout y 2. 对 s ∈ {y, y*}，在 s 的 token 上各构造 None^s、Cross^s、Self^s 3. 在两个方向上分别求三个目标；teacher 全部 detach，梯度只从学生端走 4. 按系数合成总损失，反传，更新 LoRA 参数 5. 周期性把当前 LoRA 拷进纠缠蒸馏 teacher 用的共享快照

容易看漏的细节：三种 teacher 的来源并不相同。两个纠缠蒸馏的 teacher 用的是周期性同步的 LoRA 快照（所以它跟得上学生，但不会即时跟随、避免自我追逐）；而推理锚和特权锚的 teacher 用的是停梯度的 LoRA-off 基座策略。

实现上，散度 D 取的是分量裁剪的全词表前向 KL，训练全程用 LoRA。特权信息永远不进推理 prompt，所以 DAPD 不带来任何推理开销。

规模趋势：这是全文最值得记的一条

把五个规模摆在一起，两条曲线的走向完全不同：

相对 Base 的推理增益1.7B4B8B14B32B
OPSD+5.19+1.39≤ +0.28（8B 至 32B）
DAPD——+2.41+2.13+3.06

「—」表示原文正文未逐项给出这两个规模下 DAPD 相对 Base 的数值，只报告了 8B 至 32B 三档。

OPSD 的收益随规模蒸发，DAPD 的不但没蒸发，32B 上还是最高的。论文给的解释值得单独记住：

为什么模型越大，特权幻觉越贵

模型越大，它自己的 rollout 里本来就含有越多有用的推理和自我纠错。而 OPSD 蒸的那个 teacher 可以靠参考答案跳过这些步骤——它不需要自我纠错，因为它已经看过答案了。于是特权幻觉的代价随规模上升，正好抵消了 rollout 变好带来的收益。DAPD 靠信息对等的监督把这部分收益保住了。

06什么时候这套做法不成立

三条限制，加一条论文自己挖出来的出路。

  • 训练开销明显上去了。一个 minibatch 要构造多个锚定分布，还要在两个方向上各算一遍——每个样本的前向次数是 OPSD 的数倍。推理端零额外开销，所以这是一笔纯训练时的账，值不值得取决于你的算力结构。
  • 权重需要按规模重标定。参考引导权重 λ 从 1.7B 上的 0.5 降到 4B / 8B / 14B 上的 0.2；两个特权锚的权重也各自随规模变化。论文把这个现象总结成可靠性与可达性的权衡随规模移动——小策略的 rollout 更吵，需要可靠参考来纠偏；大策略的轨迹更可信，更适合待在自己推理时的分布附近。换架构或换规模，这几个权重得重调。
  • verified-rollout 变体依赖自动正确性信号。开放式任务上没有 verifier，这条路就走不通。

一条顺带挖出来的出路：其实可以不要人工参考

既然轨迹本身也能当引导源，论文顺手问了一个更激进的问题：能不能干脆不要参考解答？

做法是采两条独立的 rollout u 和 v（相同就重采），拿 u 顶替参考侧、v 当轨迹侧。两条都是 on-policy、都可能是错的。结果：

这说明第二条轨迹并不冗余——双源结构本身就有价值，不必依赖人工整理的参考解答。再加一个 verifier 只是锦上添花。对没有高质量参考解答、但有自动校验手段的场景（代码、可判定的数学、带环境反馈的 agent 任务），这是一条现成的路。

如果只带走一句话

teacher 比学生更强不是问题，teacher 比学生多看到东西才是问题。想给学生更强的监督时，先问一句：这份监督里有多少是学生在推理时复现得出来的？复现不出来的那部分，不会变成能力，只会变成腔调。
