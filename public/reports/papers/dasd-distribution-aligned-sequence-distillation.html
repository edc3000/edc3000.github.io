核心结论

01 · 覆盖范围

低温样本容易学但模式窄，高温样本模式广却难学。论文把二者改成先低温、后高温的课程，而不是二选一。

02 · 学习方向

DAS 优先保留 teacher 高概率、student 低概率的回答，让 SFT 的“提高目标概率”更可能朝正确方向移动。

03 · 推理状态

最后让 student 自己生成前缀，再由 teacher 修订偏离后的后缀，把训练输入拉近真实 autoregressive inference。

01 · PROBLEM

SFT 把完整分布压成了一个回答

论文重新解释了一个常见做法：在 teacher 生成的 CoT 上做 SFT，本质上是 sequence-level distillation 的采样近似。问题不在 SFT 无效，而在这个近似丢掉了哪些信息。

理想目标是让 student 的完整回答分布接近 teacher。给定问题 x，所有可能回答组成集合 Y；真正的目标会按 teacher 对每个回答的概率加权，而不是把所有正确回答视为等价。

DKL(pT(y|x)∥pS(y|x)) LSEQ≈−logpS(y^|x)
上式是论文式（1）的目标；下式是只采一个 teacher 回答后的 SFT 近似。

一旦用单个采样回答 ŷ 替代整个 pT(y|x)，训练就只知道“把这条轨迹概率推高”，却不知道 teacher 的其他模式，也不知道 student 原来已经把哪些部分估得过高。

MISMATCH A

teacher 模式覆盖不足

低温或随机采样集中在少量高概率回答；高温能看见罕见模式，却混入更多噪声和难学轨迹。

MISMATCH B

目标超出 student 可学范围

SFT 会统一提高目标 token 概率。若 student 本来就比 teacher 更确信某段内容，梯度反而可能把二者推得更远。

MISMATCH C

teacher forcing 与自由生成不同

训练总是读到 teacher 的正确前缀；推理只能接着自己的历史生成，早期偏差会在长 CoT 里累积。

论文真正优化的对象

不是某个 reward，也不是额外的 RL policy；它优化的是拿哪些完整回答做 SFT，以及这些回答如何覆盖 teacher 分布、匹配 student 能力并接近自由生成状态。

02 · CONTEXT

三种蒸馏接口的约束

DASD 没有选择完整 logit matching。它保留 sequence-level SFT 的跨模型兼容性，只增加“已生成 token 的概率”和一次 student 自生成。

这里的边界很关键：DAS 不需要 teacher 对整个词表给概率，也不需要 teacher 为student 自己生成的每个 token打分。它只比较 teacher 已生成回答在两边的概率，因此 gpt-oss-120b 与 Qwen3-4B 的词表和 tokenizer 不同也能工作。

理论起点：Sequence-Level Knowledge Distillation 与 on-policy distillation
  • Kim & Rush 在 EMNLP 2016 提出 sequence-level knowledge distillation，用搜索得到的完整序列近似 teacher 分布。
  • 近年的 reasoning data distillation 把搜索改成 teacher 采样，再用正确性、长度和多样性规则过滤。
  • On-policy distillation 让 student 先生成，再由 teacher 提供监督，能缓解分布偏移，但通常要求更强的 teacher 打分接口。
  • DASD 的位置介于两者之间：主体仍是离线 teacher responses，最后只加一小段 mixed-policy 修订。

04 · DIVERGENCE-AWARE SAMPLING

DAS 优先学习 teacher 高、student 低的句子

论文把完整回答按句切开，比较 teacher、蒸馏前 student 和蒸馏后 student 对同一句子的概率，由此区分四种来源模式。

对句子 s 中每个 token 的条件概率取几何平均，得到模型 M 对整句的概率。这个归一化让不同长度的句子可以比较。

pM(s)=exp(1|s|∑i=1|s|logpM(ti|t<i,x))

Teacher Sentence DAS 重点
pT ≫ pS

teacher 明显更确信、student 原先不熟悉。SFT 把这类句子推高，最不容易出现“student 已经过度自信却还被继续推高”的错误方向。

Student Sentence
pS ≫ pT

student 原先更确信。若 teacher 并不支持这段内容，普通 SFT 仍可能提高它的概率，产生误导梯度。

Shared Sentence
pT ≈ pS ≈ pD

teacher 与 student 本来都支持，蒸馏前后变化小。这类句子不是主要的新知识来源。

Boosted Sentence
pT ≈ pS，pD 更高

teacher 与 student 原先都已有，训练后却被额外放大。论文观察到它与正确率可能负相关，但训练前无法用两模型直接识别。

teacher-generated response保存文本与 teacher 对已采样 token 的概率
→
local student scoring用 student tokenizer 重新计算同一回答的 token / sentence 概率
→
response ranking / selection优先保留 Teacher Sentences 丰富的完整回答

  • 背景色：把每个位置归入 Teacher、Student、Shared、Boosted 四类；这是一种 provenance 分解，不是人工语义标签。

相关性分析中，Teacher Sentence 在正确回答里的占比持续更高；论文据此把“teacher 高、student 低”当作更安全的学习信号。相同 50K 数学样本预算下，T=1.0 的 DAS 把 AIME25 从随机采样的 76.1 提到 79.2，甚至略高于 100K 随机样本的 78.9。

这仍然不是因果证明

四类句子与正确率的关系来自相关性分析；论文也明确把 Boosted Sentence 的负相关解释写成 conjecture。DAS 的价值由后续受控采样实验支持，但“为什么这类句子有效”的机制证据仍有限。

05 · MIXED-POLICY DISTILLATION

teacher 从 student 已走过的前缀继续

前两阶段仍是 off-policy：student 训练时只看 teacher 写出的历史。最后一阶段把 student 自己的状态带进数据，再让 teacher 对偏离处提供定向修订。

teacher reference
设定变量 → 推导关键约束 → 排除错误分支 → 得到答案
student rollout
设定变量 → 漏掉边界条件 → 进入冗长分支 → 达到 1.5× 长度上限
random cut
设定变量 → 漏掉边界条件 ｜ 在回答后半段随机截断
mixed-policy data
student 自生成前缀 → teacher 从这个真实前缀纠偏并完成答案

具体配方是：从 DAS 数据中抽 50K questions，让上阶段 student 重新生成；把最大长度设为对应 teacher 回答的 1.5 倍，找出 15K 个截断回答；在其后半段随机选择位置，丢弃后缀并让 teacher 重写。质量过滤后得到 12.7K 个 mixed-policy 样本。

保留 student 前缀

训练看到真实偏差

如果把 student 部分全部 mask 掉，模型又只在 teacher 后缀上学习，失去 on-policy 状态带来的作用。

teacher 只修后缀

监督集中在偏离之后

teacher 不重写整条答案，而是从 student 已经进入的状态继续，监督更贴近推理时会遇到的错误上下文。

轻量增量

收益小但一致

最终阶段对五个 benchmark 的提升为 +0.3 到 +0.9；它主要修补 exposure bias，不承担能力冷启动。

08 · BOUNDARIES

448K 不是一份轻量、可直接复制的配方

样本数很省，但长 CoT 的 token、生成和评测成本仍高。更准确的判断是：这是一条数据效率高、接口要求适中，但算力并不低的蒸馏管线。

≈7.2B

仅前两阶段回答的 token 量。根据论文 Figure 8 各领域 token 数相加：低温约 1.45B，高温约 5.77B；还没有计入 12.7K mixed-policy 样本。这个数字是从图中求和得到的近似值。

teacher 接口仍有门槛

DAS 不要完整词表 logits，但要 teacher 返回已生成 token 的 logprobs。只给文本的闭源 API 不能直接复现。

validation / test 边界不清

论文没有独立验证集，也说温度组合可按 evaluation performance 选择；最终 benchmark 是否完全未参与选择没有说明。

64K 训练上下文并不便宜

全流程使用 64K cutoff、ZeRO-3、Liger kernels 和 global batch 64；“样本少”不代表普通实验室可以低成本复现。

mixed-policy 仍是定向补丁

它只从截断、明显偏离的 student 回答构造小规模修订，不是持续在线的 on-policy distillation；论文也把进一步改进列为未来工作。

句子来源是概率归因

Teacher Sentence 表示 teacher 相对更支持，不表示这句话只能由 teacher 产生；四类名称不应被读成真实作者身份。

当前不含 agent 能力

带 function calls 的回答被过滤；知识检索、工具使用与更完整的 agentic reasoning 被留到未来工作。
